# hittamin GPS — Legal & Support site

Public GitHub Pages site hosting the legal and support pages for the
**hittamin GPS** iOS app (`se.hittamin.gps`).

Served at: <https://pikkemaat.github.io/hittamin-gps/>

| Page | URL |
| --- | --- |
| Privacy Policy | <https://pikkemaat.github.io/hittamin-gps/privacy/> |
| Terms of Use | <https://pikkemaat.github.io/hittamin-gps/terms/> |
| Support | <https://pikkemaat.github.io/hittamin-gps/support/> |

These URLs are referenced from the app (`HittaminGPSLegal`) and in App Store
Connect metadata. Pages are bilingual (Svenska / English), static HTML, no
dependencies. The app collects no data, has no server, and uses only Apple
CoreLocation / MapKit / StoreKit.

The app source lives in the private repo `pikkemaat/hittamin-gps-ios`.
